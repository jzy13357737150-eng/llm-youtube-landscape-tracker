Methodology

Support material

The pipeline is captions-first, transcript-grounded, and designed for scheduled reruns. Rows store transcript status, summary source, and short evidence snippets so reviewers can inspect how summaries are produced.

  • Watch source: YouTube channel feeds
  • Transcript source: captions via transcript fetcher
  • Structured output: captions-first extraction with optional LLM enrichment
  • Fallback mode: deterministic heuristics plus fixture preview
  • Deployment target: GitHub Pages via scheduled GitHub Actions
